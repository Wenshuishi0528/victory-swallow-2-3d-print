# v1.0.0

Initial public release of the unofficial fan-made Victory Swallow 2 color-separated 3D printable model.

## Included

- Print-ready Bambu Studio 3MF project
- Target width about 20 cm
- Four-color PLA setup: yellow, black, red, white
- Preview images
- Print and assembly notes
- CC BY 4.0 license notice for the contributor's original work
