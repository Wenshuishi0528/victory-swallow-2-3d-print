# Changelog

## v1.1.0 - 2026-07-04

- Fixed a blocking printability issue in the previous v1.0.0 release.
- Updated the main printable 3MF file to `victory-swallow-2_20cm_4color_v1.1.0.3mf`.
- Added real print photos from the author's 0.4 mm nozzle test print.
- Added bilingual nozzle guidance: use a 0.2 mm nozzle for the original-scale model; for 0.4 mm nozzles, scale to at least 120%.
- Clarified that the cover photo was printed with a 0.4 mm nozzle, has fair detail precision, and was assembled with glue.

## v1.0.0 - 2026-07-03

- Initial public release.
- Added print-ready 20 cm, four-color Bambu Studio 3MF project.
- Added preview images, print guide, assembly guide, attribution notes, and CC BY 4.0 license.
